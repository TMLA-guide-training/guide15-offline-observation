# 主課合併資料指南

1. 收集每位教官的完整 JSON，原檔另存唯讀備份，記下手機來源、教官與交付時間。檔名含活動、教官、時間與隨機尾碼，請勿改名後覆蓋舊檔。
2. 在固定裝置、固定 HTTPS origin 開啟 App。先匯出主課裝置目前完整 JSON，保留合併前狀態。
3. 一次選一個 JSON，先查看來源裝置、活動與「新增／略過／衝突／錯誤」。錯誤未排除不得寫入，可按取消。
4. 相同 `assessmentId + eventId` 且內容完全相同會略過。同一 ID 不同內容逐筆對照完整欄位；選保留本機或採用匯入版本，**含刪除狀態**，無預選。兩個活動同 eventId 視為不同事件。
5. 不同 ID 即使相似也保留。同一參加者、同類且時間相距 5 分鐘內僅提示人工檢視；不同教官可能記到同一事件。不要依筆數排名或計分。
6. 完成後確認新增、略過與已處理衝突筆數，查看匯入歷史。若預覽期間有其他分頁修改，系統會中止；重新選檔預覽再處理。
7. 備份名單中已有相同 ID 會保留主課本機名單。需要更正姓名請使用名單 CSV／JSON 的獨立預覽流程；既有事件姓名快照不隨之更改。相同路線 SHA 保留本機核定地標設定，新增路線保留來源內容。
8. 待核對編號透過人工比對後編修事件，選正式編號；不要任意對號。不同教官使用相同臨時編號時也須人工核對。
9. 還原至新裝置後先在設定選教官、活動與路線。來源裝置 ID 只存於備份來源與匯入歷史，不覆蓋新手機裝置 ID。
10. 再次匯出合併後完整 JSON，確認檔案可在另一個測試來源匯入預覽；CSV 可用 Excel／Sheets 查看（含 deletedAt，分析前需人工處理刪除狀態）。CSV 不作完整還原檔。

匿名討論版移除自由文字、姓名、座標等資訊；仍含參加者編號與時間，僅交給授權討論者。正式備份請依主課規定保管、決定留存期限並在確認備份後清除各手機資料。不要將真實備份放入程式碼倉庫或公開網站。
