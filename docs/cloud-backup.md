# 雲端備份上傳（Google Apps Script）

啟用後：
- **自動上傳**：每次儲存或刪除事件後，有網路時在背景上傳整支手機的完整備份；沒網路就排隊，連網、回到前景、開啟 App 或每 2 分鐘時自動補傳。上傳期間又有新變更，完成後會再傳一次。
- **頂端狀態**：「☁ 已同步」或「☁ N 筆待上傳」（自上次上傳後有變更的事件數）。
- **每支手機一份檔**：雲端資料夾「04_評測紀錄APP / 教官備份上傳」裡每支手機只有一個 `備份_<教官>_<裝置碼>.json`，每次上傳覆寫成最新版。雲端硬碟會自動保留檔案的版本紀錄。
- 「備份與合併」頁的「☁ 完整 JSON 備份（上傳雲端）」可立即上傳；「↓ 另存到手機」下載一份檔案。這支手機還沒取得通行碼時，按鈕維持「↓ 完整 JSON 備份」（下載）。

- 上傳網址寫在 `src/upload-config.ts`（`UPLOAD_URL`），空字串表示不啟用。
- 通行碼：`SHA-256("guide15-upload:" + 名單密碼)` 的 16 進位字串。教官用名單密碼解鎖名單時，App 會自動算出並存在本機 localStorage，不會放進 JSON 備份。改用檔案匯入名單的手機，要在「備份與合併」頁輸入名單密碼啟用。
- 上傳網址寫在公開網站裡，但沒有通行碼的上傳會被拒絕。外人也無法透過這個網址讀取資料夾。
- 程式碼：`scripts/apps-script/Code.gs`。

## 一次性設定（資料夾擁有者的 Google 帳號）

1. 開啟 https://script.google.com → **新專案**，專案名稱例如「15期評測備份上傳」。
2. 刪除編輯器裡的預設內容，貼上 `scripts/apps-script/Code.gs` 的全部內容，按儲存。
3. 左側 **⚙ 專案設定** → 最下方 **指令碼屬性** → **新增指令碼屬性**：屬性 `UPLOAD_TOKEN`，值為教官上傳通行碼；再新增 `LEAD_TOKEN`，值為總教官讀取通行碼（都由 Claude 依密碼算出提供）。儲存。
4. 回到 **編輯器**，上方函式選單選 `testSetup` → **執行**。第一次會要求授權：選你的帳號 →「進階」→「前往（不安全）」→ 允許。這是你自己的程式，畫面上的「不安全」是因為它沒有送 Google 審核。
   執行紀錄出現「上傳資料夾：…」和「UPLOAD_TOKEN 已設定：true」就完成了，資料夾裡也會多一個「教官備份上傳」。
5. 右上 **部署 → 新增部署作業** → 類型選 **網頁應用程式**：
   - 執行身分：**我**
   - 誰可以存取：**所有人**
   按「部署」，複製「網頁應用程式網址」（`https://script.google.com/macros/s/…/exec`）。
6. 把網址交給 Claude，Claude 會填入 `src/upload-config.ts` 並發版。

## 總教官一鍵合併

「備份與合併」頁的「☁ 一鍵合併雲端資料夾的全部教官備份」：輸入**總教官密碼**，按「讀取雲端全部備份」，App 會取回「教官備份上傳」資料夾的備份。
- 每台裝置只取最新一份，因為每次上傳都是該手機的完整快照。
- 同一事件出現在多份時取最後修改的版本。
- 所有備份合併成**一次預覽**，與本機不同的事件逐筆選擇，確認後才寫入。

總教官密碼與名單密碼不同，只給總教官。教官的名單密碼只能上傳，不能讀取別人的備份。
Apps Script 指令碼屬性 `LEAD_TOKEN`＝`SHA-256("guide15-lead:" + 總教官密碼)` 的 16 進位（由 Claude 算出提供）。

沒有網路或不使用雲端時，也可以在「或選擇 JSON 備份檔」一次多選多個檔案合併。

## 更換名單密碼時

到 Apps Script **專案設定 → 指令碼屬性**，把 `UPLOAD_TOKEN` 改成新密碼的通行碼。舊通行碼會失效，教官的 App 會顯示「上傳通行碼錯誤或已更換」，請教官在「備份與合併」重新輸入新密碼。

## 修改程式碼後（例如 V1.6 改為每支手機一份檔）

**部署 → 管理部署作業** → 鉛筆圖示 → 版本選「新版本」→ 部署。網址不會變。

## 評測結束後

在 Apps Script 刪除指令碼屬性 `UPLOAD_TOKEN`，或封存該部署，就不再接受上傳。備份檔留在雲端資料夾，由總教官保管。
