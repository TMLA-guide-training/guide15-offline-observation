# 雲端備份上傳（Google Apps Script）

啟用後，教官按「☁ 完整 JSON 備份（上傳雲端）」會直接上傳到雲端資料夾「04_評測紀錄APP / 教官備份上傳」，不下載檔案，iPhone 也不會跳出檔案預覽。要在手機留一份，另外按「↓ 另存到手機」。
離線時會跳出提醒並標記「待上傳」，連網後自動以最新資料補傳，不用重按。這支手機尚未取得通行碼時，按鈕維持原本的「↓ 完整 JSON 備份」（下載）。

- 上傳網址寫在 `src/upload-config.ts`（`UPLOAD_URL`），空字串表示不啟用。
- 通行碼：`SHA-256("guide15-upload:" + 名單密碼)` 的 16 進位字串。教官用名單密碼解鎖名單時，App 會自動算出並存在本機 localStorage，不會放進 JSON 備份。改用檔案匯入名單的手機，要在「備份與合併」頁輸入名單密碼啟用。
- 上傳網址寫在公開網站裡，但沒有通行碼的上傳會被拒絕。外人也無法透過這個網址讀取資料夾。
- 程式碼：`scripts/apps-script/Code.gs`。

## 一次性設定（資料夾擁有者的 Google 帳號）

1. 開啟 https://script.google.com → **新專案**，專案名稱例如「15期評測備份上傳」。
2. 刪除編輯器裡的預設內容，貼上 `scripts/apps-script/Code.gs` 的全部內容，按儲存。
3. 左側 **⚙ 專案設定** → 最下方 **指令碼屬性** → **新增指令碼屬性**：屬性 `UPLOAD_TOKEN`，值為通行碼（由 Claude 依名單密碼算出提供）。儲存。
4. 回到 **編輯器**，上方函式選單選 `testSetup` → **執行**。第一次會要求授權：選你的帳號 →「進階」→「前往（不安全）」→ 允許。這是你自己的程式，畫面上的「不安全」是因為它沒有送 Google 審核。
   執行紀錄出現「上傳資料夾：…」和「UPLOAD_TOKEN 已設定：true」就完成了，資料夾裡也會多一個「教官備份上傳」。
5. 右上 **部署 → 新增部署作業** → 類型選 **網頁應用程式**：
   - 執行身分：**我**
   - 誰可以存取：**所有人**
   按「部署」，複製「網頁應用程式網址」（`https://script.google.com/macros/s/…/exec`）。
6. 把網址交給 Claude，Claude 會填入 `src/upload-config.ts` 並發版。

## 更換名單密碼時

到 Apps Script **專案設定 → 指令碼屬性**，把 `UPLOAD_TOKEN` 改成新密碼的通行碼。舊通行碼會失效，教官的 App 會顯示「上傳通行碼錯誤或已更換」，請教官在「備份與合併」重新輸入新密碼。

## 修改程式碼後

**部署 → 管理部署作業** → 鉛筆圖示 → 版本選「新版本」→ 部署。網址不會變。

## 評測結束後

在 Apps Script 刪除指令碼屬性 `UPLOAD_TOKEN`，或封存該部署，就不再接受上傳。備份檔留在雲端資料夾，由主課保管。
