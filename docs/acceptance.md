# 手機飛航模式驗收記錄表（待實機填寫）

至少 iOS Safari、Android Chrome 各一輪，兩者都測「一般分頁」及「主畫面安裝後」。桌面自動化通過不代表這四組實機通過。

記錄：日期／測試人／手機型號／OS 版本／瀏覽器版本／HTTPS 網址／活動 ID／GPX SHA／一般或安裝模式／結果／異常與截圖。每次使用虛構名單，勿將真實事件上傳測試網站。

## A. 連網準備

- [ ] 開啟 HTTPS，無資源載入錯誤，右上顯示「離線資源已就緒」。
- [ ] 首次開啟出現「輸入姓名」「匯入參加者名單」兩步驟，完成前看不到選單；完成後關閉重開不再要求設定。
- [ ] 新增事件的地標選單有 11 個地點，不含人形立牌與平等里；選地標會帶入文字地點。
- [ ] 主畫面圖示名稱為「15期評測紀錄」；選單下方顯示版本號；「名單與設定」可按「檢查更新」。
- [ ] 匯入虛構參加者 CSV（含 Excel 存的 Big5 CSV），預覽筆數；含缺失、重複編號資料需阻止寫入。
- [ ] 主畫面安裝成功，從圖示開啟；確認是否與一般瀏覽模式共用資料，將結果記錄，勿假定。
- [ ] 設定手機本地時間與時區正確；記錄教官與活動 ID。

## B. 真正離線重啟

- [ ] 開啟飛航模式，**另外確認 Wi-Fi 與行動數據均關閉**。
- [ ] 從最近使用 App 畫面完全關閉 Safari／Chrome 及已安裝 App（勿清除瀏覽器資料）。
- [ ] 從圖示或原網址完全重開，App 仍載入，教官、名單與路線仍在。
- [ ] 新增正向、待改善、安全三類；正向／待改善沒有安全快捷行為；安全剛好 S01–S05 與 S99，自訂名稱必填。
- [ ] 缺具體事實／文字地點／參加者不能保存；空白提醒狀態仍是尚未記錄。示例不代填。
- [ ] 每筆看到成功時間及清單事件。離開未存表單有提示；選取消後文字仍在。
- [ ] GPS 不授權、逾時或收不到訊號，仍可用文字儲存。按一次才取一次，沒有持續追蹤。
- [ ] 可取得 GPS 時顯示原始座標與精度；差精度提醒，可取消推測保留 GPS，也可全部移除。地點文字不被自動取代。
- [ ] 編輯一筆、查詢編號／姓名、篩選類別／教官／日期。再完全關閉重開，新增與編修都仍在。
- [ ] 刪除需確認，清單消失，JSON 可看到 deletedAt。
- [ ] 關閉一個模式後以另一模式開啟，確認資料是否分離；分離時各自備份與驗收，不互相覆蓋。

## C. 備份與合併（可全程離線）

- [ ] 匯出完整 JSON／CSV 到手機檔案，實際打開檔案確認非空；檔名含活動、教官、日期時間。
- [ ] CSV 在 Excel、Google Sheets 顯示繁中正確，引號、逗號與換行保留；以 = + - @、空白或 Tab 開頭的文字不執行公式。
- [ ] 有臨時編號時匯出警示，JSON／CSV 都含待核對標記。
- [ ] 重複匯入同一 JSON，新增 0，不重複事件。
- [ ] 修改同一 ID 的文字再匯入，必須出現衝突；未逐筆選擇無法確認。取消不改資料。
- [ ] 分別測保留本機、採用匯入（含刪除狀態）；匯入完成顯示結果與來源歷史。
- [ ] 不同 ID、同人同類相近時間保留並提醒；不能自動合併為一筆。
- [ ] 另一支手機也離線記錄，再以 JSON 匯入主課手機，不相互覆蓋。
- [ ] 新測試裝置匯入 JSON 可還原名單、事件與原始路線；再手動選教官、活動與路線。裝置 UUID 不沿用來源手機。
- [ ] 匿名討論版沒有姓名、自由文字與 GPS；不可用於還原。

## D. 邊界與操作速度

- [ ] 不同活動清單隔離；切換教官／GPX 後舊事件 snapshot 與 routeVersion 保留。
- [ ] GPS 位於閉合起終點、接近不同路段時顯示候選，沒有肯定的自動路段名稱。
- [ ] 匯入多軌跡／斷段 GPX 會明確拒絕，原始資料仍在；錯誤備份不寫入。
- [ ] 多分頁同事件修改，過期版本保存被阻止，表單保留。預覽後另一分頁改事件，匯入全部中止。
- [ ] 使用 `examples/1000-events.backup.json` 測 1000 筆：匯入、搜尋、翻頁、編輯與匯出；記錄實際手機耗時與是否卡頓。
- [ ] 分別計時一般正向／待改善事件，從按新增到儲存成功；各至少 5 次，記錄中位數與最慢值。30 秒是體驗目標，尚未有實機結果。
- [ ] 未出現分數、排名、個人硬性關門或自動裁決。
- [ ] 已備份後才測清除流程；取消任一步都保留資料，完成雙重確認後本機資料消失。
- [ ] 保持舊版未存表單開啟時部署新版本，不強制重載；儲存後關閉所有分頁再開可更新，既有 IndexedDB 仍在。
