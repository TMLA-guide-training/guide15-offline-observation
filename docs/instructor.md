# 教官一頁操作指南

> App 內也有相同內容：選單「？ 使用說明」（首次設定頁下方也可展開），離線可看。

1. **出發前連網準備**：用一般瀏覽模式開啟正式 HTTPS 網址，確認右上「離線資源已就緒」，加入主畫面。不要用私人模式。先做一次飛航模式重開測試。
2. **第一次開啟**：App 會先要求兩個步驟，完成前無法使用：
   - 步驟 1：輸入自己的姓名（教官不另建名單）。
   - 步驟 2：輸入總教官私下提供的「名單密碼」，按「解鎖並載入名單」，檢查預覽後按「確認匯入」。若沒有密碼欄，或總教官改給檔案，則選擇名單 CSV／JSON 匯入。
   完成後下次開啟不需再設定。之後要改姓名或重新匯入名單，到「名單與設定」。正式活動 ID 為 `guide15-2026-12-13`。
3. **名單格式**：CSV 第一列 `participant_id,name`（或 `編號,姓名`），之後每列一位。Excel 存成「CSV UTF-8」或一般 CSV 皆可；App 內有「下載名單範例 CSV」。
4. **新增**：選參加者、三大類、事件時間，文字地點可不填（事後可補）；描述親眼看到的具體事實。安全類提供 S01–S05 與其他。待改善及安全類可補提醒、反應及處置；安全類另記「是否已通知總教官」。未填代表尚未記錄。
5. **找不到參加者**：選「臨時編號／待核對」，自行填唯一臨時編號，勿借用別人的編號；事後編修選回正式參加者。
6. **沒有 GPS 也能記**：文字地點與 GPS 都可不填，建議至少填一項以便事後知道地點；地點可從地標選單帶入再補充。GPS 按鈕僅取一次位置。被拒、逾時、不準都可繼續。推測顯示「約」與候選，不是導航；可取消推測或移除 GPS。
7. **確認儲存**：按「儲存到本機」，看到成功時間並回到清單才算完成。失敗時留在表單，保留文字後處理空間或其他分頁問題。切勿直接清除瀏覽器資料。
8. **查詢與更正**：清單可依編號、姓名、文字、日期、教官與類別篩選。「查看／編輯」補充事實。刪除需確認，完整 JSON 仍保留軟刪除標記。
9. **備份會自動上傳**：每次儲存或刪除紀錄後，有網路時 App 會在背景把整支手機的備份上傳到總教官的雲端資料夾。畫面上方會顯示「☁ 已同步」或「☁ N 筆待上傳」（黃色）。山上沒訊號時紀錄會排隊，回到有訊號的地方打開 App 就會自動補傳，請確認變成「已同步」。也可到「備份與合併」按「☁ 完整 JSON 備份（上傳雲端）」立即上傳，或按「↓ 另存到手機」留一份檔案。若畫面上方沒有 ☁ 標示（雲端未啟用），請在「備份與合併」輸入名單密碼啟用，或下載完整 JSON 後依總教官指示交付。

重大安全情況先現場處理，並以無線電通知總教官，再補填。儲存不等於通報。事件筆數不代表分數或錄取結果。不要刪除 App、清除瀏覽器資料或更換網域後才備份。

**版本更新**：版本號顯示在選單下方與「名單與設定」。連網時 App 會自動檢查新版本，沒有未儲存的表單時會自動更新並重新載入；也可在「名單與設定」按「檢查更新」。正在填寫的表單不會被強制中斷，儲存或取消後才更新。
